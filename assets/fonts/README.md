# Fonts

Anti-aliased glyph atlases generated by `tools/fontgen.py` (`*.bin`, `index.rs`).

| Face | Source | SHA-256 |
|------|--------|---------|
| Ui / UiBold | Inter variable (`Inter[opsz,wght].ttf`, google/fonts `ofl/inter`), wght 400 / 600 | `29160a80ff49ddcab2c97711247e08b1fab27a484a329ce8b813d820dc559031` |
| Mono | DejaVu Sans Mono (8x16 and 16x32 cells) | `54bf827eb99404e8f430c330ad30f063334f637eba0109b6a18d4f566a8e9dd8` |
| Fallback | DejaVu Sans / Sans Bold, per missing glyph | `57f73e11...c84e` / `a4c5bc45...f890` |

Regenerate (needs Python 3, Pillow, fontTools; output is byte-identical):

    python3 tools/fontgen.py --download

`--download` fetches Inter once into `assets/fonts/.cache/` (git-ignored) and
refuses to continue if the hash differs. Licences: `LICENSE-Inter-OFL.txt`,
`LICENSE-DejaVu.txt`.

Binary layout (little-endian): 12-byte header (`LFA1`, size, cell_w, ascent,
descent, line_h, pad, count:u16), then `count` 12-byte records sorted by code
point (cp:u16, advance, bearing_x:i8, top:i8, w, h, pad, offset:u32), then 8-bit
coverage rows.
